How many types of compilation does Angular provide?

Angular provides two types of compilation:

  • JIT (Just-in-Time) Compilation: Happens at runtime in the browser. Compiles the Angular application in the browser as it loads, offering faster development builds but slower performance in production.
  • AOT (Ahead-of-Time) Compilation: Happens during the build time. Compiles the Angular application into efficient JavaScript before it runs in the browser, resulting in faster rendering and better performance in production.

In JIT compilation, the application compiles inside the browser during runtime.

In AOT compilation, the application compiles during the build time.
