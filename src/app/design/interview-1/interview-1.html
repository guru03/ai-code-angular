In Angular, pure pipes are the default type of pipe. They only run again when Angular detects a "pure" change, such as an updated primitive value (like a string, number, boolean, or symbol) or a new object reference for arrays, objects, or dates. If an object or array is modified in place without changing its reference, the pipe will not re-execute.

How many types of compilation does Angular provide?

Angular provides two types of compilation to translate your application code into efficient JavaScript before running it. In JIT compilation, the application compiles inside the browser during runtime. In AOT compilation, the application compiles during the build time.

JIT (Just-in-Time) Compilation: Happens at runtime in the browser. Compiles the Angular application in the browser as it loads, offering faster development builds but slower performance in production.

AOT (Ahead-of-Time) Compilation: Happens during the build phase before the application is run. Compiles the application into efficient JavaScript code ahead of time, which leads to faster loading and better performance. Recommended for production builds.
