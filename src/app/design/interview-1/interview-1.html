In Angular, pure pipes are the default type of pipe. They only run again when Angular detects a "pure" change, such as an updated primitive value (like a string, number, boolean, or symbol) or a new object reference for arrays, objects, or dates. If an object or array is modified in place without changing its reference, the pipe will not re-execute.

This behavior helps improve performance by avoiding unnecessary recalculations during change detection.
