            How to remove the first element from an array in JavaScript?
        


        
        

            The code initializes an array arr with values
            [5, 6, 7]. The
            slice(1)
            method creates a new array, excluding the first element, resulting in [6, 7]. Finally,
            console.log(arr) outputs the modified array to the console.
        


        
        

            

                1
                Using shift()
                (mutates
                    the array)
            


            
            

                
                

                    

                        
                        
                        
                        solution.ts
                    

                    JAVASCRIPT
                

                
                
let arr = [10, 20, 30, 40];
arr.shift(); // removes the first element

console.log(arr); // [20, 30, 40]

            


            
            

                Output:
                [20, 30, 40]
            

        


        
        

            

                2
                Using slice()
                (returns
                    new array)
            


            
            

                
                

                    

                        
                        
                        
                        solution.ts
                    

                    JAVASCRIPT
                

                
                
let arr = [10, 20, 30, 40];
                    let newArr = arr.slice(1); // new array without the first element

                    console.log(newArr); // [20, 30, 40]

            





            
            

                Output:
                [20, 30, 40]
